Everything in uze is clickable, including every key hint on screen; keys are the shortcut. `F1` shows the ones that
work where you are, along with the rarer actions that have no key of their own.

When uze asks you something, the arrows move between the answers, `Enter`
takes the one you are on and `Esc` cancels.

## Defaults

| Keys | Action |
| --- | --- |
| `Alt+N` | New agent |
| `Alt+.` | The selected agent's actions: rename, continue in another harness, move to a worktree, close |
| `Ctrl+T` | New shell tab |
| `Alt+S` | New space |
| `Ctrl+W` | Close the tab |
| `F2` | Rename the selection |
| `Alt+↑` / `Alt+↓` | Previous / next agent |
| `Alt+1` … `Alt+9` | The nth tab on the strip: the agent, then the shells beside it |
| `Ctrl+↑` / `Ctrl+↓` | Previous / next space |
| `Alt+X` | What the checkout intends: its changes, designs and tasks ([Spec](/docs/workspace/spec)) |
| `Alt+A` | The project's diagrams ([Architect](/docs/workspace/architect)) |
| `Alt+G` | What the agent changed ([Code](/docs/workspace/code)) |
| `Alt+E` | The agent's files ([Code](/docs/workspace/code)) |
| `Alt+I` | [Deliver](/docs/workspace/agents#bringing-the-work-home) the agent's work |
| `Alt+P` | [Recent](/docs/workspace/agents#recent): the agents no pane carries, and what waits on you. Inside it, `/` searches, `a` shows unnamed agents too, `i` delivers, `d` discards, `Alt+.` opens the row's actions |
| `Ctrl+O` | Management, and back |
| `F1` | The keys that work here |
| `Ctrl+Q` | Quit |

Every other key goes to the agent in the pane.

## Change a key

In management (`Ctrl+O`), open **Shortcuts**, pick an action and press the new
key. The screen tells you if your terminal cannot send it.

Your changes live in `~/.uze/keys.json`, which holds only what differs from the
defaults:

```json
{
  "bindings": {
    "workspace": {
      "new-shell-tab": ["f4"],
      "close-tab": []
    }
  }
}
```

An empty list unbinds the action. Each action sits under the surface it is live
in: `workspace`, `code`, `spec`, `architect`, `preserved-work` (Recent) and so
on. Rebinding from the Shortcuts screen writes the right names for you.

<Callout type="info">
  On macOS, `Alt` shortcuts need your terminal to send Option as Meta
  (Terminal.app and iTerm2 have a setting for it).
</Callout>
