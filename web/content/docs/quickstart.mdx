title: Quickstart
description: Five minutes with each half of uze, the package manager and the workspace
---

You have uze [installed](/docs/installation) and at least one agent set up.
Open a terminal in any Git repository. The two parts below are independent:
start with whichever you came for.

## Package manager: one plugin, every agent

### 1. Add a plugin

Plugins come from marketplaces: Git repositories that list them. Add one, then
add a plugin from it to this project:

```bash
uze market add owner/repo      # a marketplace on GitHub
uze <plugin>@<marketplace>     # add one of its plugins
```

`agents.yaml` and `agents.lock` now record it. Commit them, and whoever clones
the project runs `uze install` to get the same plugins.

### 2. Use it from any agent

Start an agent the way you always do: `claude`, `codex`, `opencode`, `agy`.
Each one has the plugin's skills, in its own format.

One plugin comes already installed: `uze`, the official one. Try it:

```text
/uze:init
```

It sets up `AGENTS.md` as the one instructions file every agent reads. In Codex
the prefix is `$`, in OpenCode `@`: see [Skills](/docs/reference/skills).

### 3. Check what each agent got

```bash
uze status             # this project: plugins, context, anything still owed
uze inspect <plugin>   # how each agent receives each part of it
```

## Workspace: two agents side by side

### 1. Open the workspace

```bash
uze workspace
```

Your project opens as a **space**. Everything on screen is clickable; `F1` lists
the keys that act right now.

### 2. Start two agents

Press `Alt+N` and pick an agent. Do it again and pick another. Give each one a
task, the way you normally would.

Each agent is a tab in the sidebar. The tab shows the name of the work once
the agent picks one, and a check when it finishes.

### 3. See what one changed

Select an agent and press `Alt+G`. You get its changed files and the diff. Press
`Alt+G` again to go back to the agent.
