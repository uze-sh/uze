description: One AGENTS.md that every agent reads

Write your project's instructions once, in `AGENTS.md` at the project root.
Every agent reads it natively: Claude Code, Codex, OpenCode and Antigravity.
Claude Code reads a `CLAUDE.md` of your own instead, when you have one with
content that does not import `@AGENTS.md`; `uze status` says when that happens.

## Set it up

Ask any agent, with the `uze:init` skill:

```text
/uze:init
```

It reads your project and whatever instructions already exist (`CLAUDE.md`,
`GEMINI.md`, …), proposes one `AGENTS.md`, and changes nothing until you agree.

## Check it

```bash
uze status
```

Says which file your instructions come from and whether every agent reads it.
If one does not, it says why: usually a `CLAUDE.md` of your own, which `/uze:init`
can fold into `AGENTS.md` with you.

## What uze writes into it

`AGENTS.md` is yours. uze only writes inside blocks it marks:

```markdown
<!-- uze:begin … -->
…
<!-- uze:end … -->
```

They hold what uze needs every agent to know, such as how this project isolates
agents. Anything you write outside them is never touched, and a block you edit
by hand is reported, not overwritten.
