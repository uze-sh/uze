description: One AGENTS.md that every agent reads

Write your project's instructions once, in `AGENTS.md` at the project root.
Every agent reads it: Codex, OpenCode and Antigravity natively, and Claude Code
through a one-line `CLAUDE.md` that uze keeps in place.

## Set it up

Ask any agent, with the `uze:init` skill:

```text
/uze:init
```

It reads your project and whatever instructions already exist (`CLAUDE.md`,
`GEMINI.md`, …), proposes one `AGENTS.md`, and changes nothing until you agree.

## Check it

```bash
uze status
```

Says which file your instructions come from and whether every agent reads it.
If one does not, `uze install` fixes it.

## What uze writes into it

`AGENTS.md` is yours. The only place uze writes is inside the blocks it marks:

```markdown
<!-- uze:begin … -->
…
<!-- uze:end … -->
```

They hold what a plugin your `agents.yaml` declares asks of every agent, and
`uze install` writes one for each such plugin, never for a plugin that is only
on your machine. Anything you write outside the blocks is never touched, and a
block you edit by hand is reported, not overwritten.

The workspace writes nothing here. An agent it launches gets its instructions
(where it works, how its work is delivered, how to name it) with its context
when it starts ([Agents](/docs/workspace/agents)), and an agent asked to write
a plugin follows the `uze:author` skill. Earlier releases put both in
`AGENTS.md`; `uze install` removes those blocks, except one you edited, which
it reports and leaves for you.

## Project skills and agents

Skills the project keeps in `.agents/skills` reach Codex, OpenCode and
Antigravity natively, wherever you start them. Agents in `.agents/agents` reach
Antigravity natively. Claude Code reads neither, and Codex does not read project
agents, so for those two they arrive through the workspace's shim: inside
`uze workspace` only. OpenCode does not receive project agents at all, because
nothing a launch hands it stays with one project. `uze status` and
`uze inspect` say which. Plugins you
install are not affected: they reach every agent everywhere.
