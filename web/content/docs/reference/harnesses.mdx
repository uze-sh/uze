Every cell here is derived from the integrations themselves: it is the plan an install takes.
Start with the overview, open the tab of the harness you use, and expand **Compare all
harnesses** when you need two side by side.

Every harness offers a plugin's agents by the same name, `<plugin>:<name>` (a subdirectory
under `agents/` joins it), and receives each agent as a file carrying only the fields that
harness reads.

**Hooks**

- Runs on: `PreToolUse`, `PostToolUse`, `Stop`, `SessionStart` (new session), `SessionStart` (resumed session)
- Can decide: `observe`, `allow`, `deny`, `ask`, `transform`
- Reaches: `shell`, `file.read`, `file.write`, `file.edit`, `search.files`, `search.web`, `agent.spawn`
- Not available here: `agent.message`
