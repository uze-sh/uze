The Google-family harness. Its plugin carries the skills, with the plugin root resolved in each,
and the MCP servers, translated; agents go to its global agents directory under their plugin
label, which a plugin's agents would lose. The agent a person starts on is not given the tool
that dispatches another, so delivered agents are reported degraded. Hooks merge into its shared
`hooks.json`; its session-start hook is one its docs do not list, so the Conformance Lab checks
it on every release.
